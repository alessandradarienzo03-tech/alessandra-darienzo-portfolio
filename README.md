## Featured Projects

### Predictive Financial & ESG Analytics for Private Companies

An end-to-end machine learning framework for forecasting financial and
sustainability performance across private companies in Campania, Italy.

The project combines:

- financial and ESG forecasting;
- data-quality management;
- Random Forest, XGBoost, LSTM, Prophet and Linear Regression;
- business-driven company segmentation;
- GenAI-assisted geographic data enrichment;
- decision-oriented economic and sustainability analysis.
