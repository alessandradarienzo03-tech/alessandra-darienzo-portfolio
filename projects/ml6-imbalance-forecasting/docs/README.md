# Documentation

This folder contains domain and modelling notes supporting the ML6 Electricity
Imbalance Forecasting project.

## Available Document

- [`imbalance_forecasting_knowledge.md`](imbalance_forecasting_knowledge.md) —
  problem context, electricity-market roles, System Imbalance structure,
  available data, modelling logic and economic evaluation framework.

The notes are derived from the knowledge material prepared for the ML6
Imbalance Forecasting Workshop and are intended to provide context for the
technical notebooks.
