# Aggregate Results

This folder contains non-confidential results derived from the modelling
pipeline.

## Tables

- `tables/model_comparison.csv`: benchmark performance across five models.
- `tables/error_by_firm_size.csv`: Random Forest error by company size.
- `tables/employment_trends_by_sector.csv`: employment-growth classification
  aggregated by economic macro-sector.

## Planned Figures
